
If your company uses Azure DevOps and has logins for GitHub Copilot, you can use it in Visual Studio (or, at least, you can try).

When you click on "sign in to GitHub" it asks you to log in with a user.

You need to use this format

```
name-lastname_COMPANYSHORTCODE
```

for example:

```
davide-bellone_XTEL
```
